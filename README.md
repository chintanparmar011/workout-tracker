# FitTrack

A Flutter + Firebase fitness app for tracking strength/bodybuilding workouts, running (GPS), nutrition, and overall progress.

## Current Status

**Setup phase complete.** No feature code yet — this is the project skeleton with Firebase wired up.

## What's Done So Far

- Flutter project created (package name: `fittrack`)
- Firebase project connected via FlutterFire CLI (`flutterfire configure`)
    - Firebase Authentication enabled (Email/Password)
    - Cloud Firestore database created
- Dependencies added in `pubspec.yaml`:
    - `firebase_core`, `firebase_auth`, `cloud_firestore`
    - `provider` (state management)
    - `fl_chart` (charts for progress)
    - `geolocator`, `google_maps_flutter` (running/GPS module)
    - `intl`
- `main.dart` initializes Firebase and confirms the connection (shows "Firebase connected ✅" on launch)
- Full folder structure planned out under `lib/` (see below) — folders exist, most files are still empty placeholders

## What's NOT Done Yet

- No models, no screens with real logic, no Firestore reads/writes
- No authentication screens (login/register UI)
- No AI features — intentionally out of scope for now (see Project Concept below)

## Project Concept

FitTrack lets users follow strength/bodybuilding workout plans and manually record their **actual** performance per set (not just "completed" — e.g. target 15 reps, actual 15/12/8), track running sessions with GPS + map + route, log food/calories, track body weight, and view progress via charts. Feedback is simple rule-based logic (e.g. completion >= 90% → "Excellent"), not AI. AI assistant is a planned future enhancement only, added after the core app works.

## Getting Started (For Teammates)

1. **Clone the repo**
   ```
   git clone https://github.com/YOUR_USERNAME/fittrack.git
   cd fittrack
   ```

2. **Install Flutter dependencies**
   ```
   flutter pub get
   ```

3. **Set up Firebase locally** (Firebase config files are gitignored — each dev needs their own local copy)
    - Install Firebase CLI: `npm install -g firebase-tools`
    - Install FlutterFire CLI: `dart pub global activate flutterfire_cli`
    - Log in: `firebase login`
    - Run: `flutterfire configure`
        - Select the existing **fit-tracker** Firebase project (ask [whoever set it up] to add you as a project member on the Firebase Console first — Firebase Console → Project Settings → Users and Permissions)
        - Select Android (and iOS if needed)
    - This generates `lib/firebase_options.dart` and platform config files locally — do not commit these.

4. **Run the app**
   ```
   flutter run
   ```
   You should see "Firebase connected ✅" on screen if setup succeeded.
